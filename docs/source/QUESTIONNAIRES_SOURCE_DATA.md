# Questionnaire Source Data

**Product:** Psychology-Based Career Assessment
**Purpose:** Source-grounded questionnaire content for implementation by the coding agent.
**Source files supplied:** `TEST 1 (PERSONALITY).pdf`, `Holland's.pdf`, and `Learning Style.pdf`.

## Critical implementation notes

- The app/product name is **Psychology-Based Career Assessment**. The supplied PDFs represent **three assessment modules**, not four: MBTI/personality, Holland RIASEC, and VARK.
- The source PDFs identify Indian School of Counselling and Healing Studies (ISCHS) workbook ownership/copyright. Before production reproduction or online administration, confirm the client has permission/licensing for the questionnaire text, scoring method, and interpretations.
- Treat the transcriptions below as a transcription of the supplied documents, not validation that the instruments are psychometrically current or licensed for online commercial use.
- Do not invent interpretation text or scoring rules. Where the source is ambiguous/incomplete, preserve the source and mark a release blocker.
- Normalised page line breaks have been joined for readability. Apparent source wording/typos are retained and noted rather than silently corrected.

## 4. Data contract and coding guidance

The companion `QUESTIONNAIRES_SOURCE_DATA.json` contains the same content in a structured form suitable for seed data or configuration. Use stable IDs and preserve source question numbers.

### Recommended common item schema

Each item should have:
- `assessment_id` and `assessment_version`
- `question_id` (stable ID, e.g. `mbti_q001`, `riasec_r_are_01`, `vark_q02`)
- `source_question_number` where applicable
- `prompt` or `statement`
- answer options with stable keys and exact text
- response type (`single_choice`, `multi_select`, or `boolean_checkbox`)
- scoring mapping only where supplied and verified
- source filename/page reference
- approval status and version metadata

### Module-specific response types

- **MBTI:** exactly one option (a or b) per question; scoring is blocked pending approved golden fixtures.
- **RIASEC:** one checkbox per inventory statement; category-specific sum from checked statements; confirm the point-per-check interpretation and review flagged text.
- **VARK:** multi-select per question is permitted by the source; use only the option-to-category mapping shown in the provided chart. Q1 remains unscored and Q15 is instruction-only unless an authorised correction is supplied.

### Product requirements for the coding agent

1. Display **Psychology-Based Career Assessment** as the product/app name, not as a fourth questionnaire.
2. Present three independent assessment modules: MBTI/personality, Holland RIASEC, and VARK learning styles.
3. Store source/version metadata so future questionnaire revisions do not silently alter existing attempts.
4. Keep raw responses separate from computed results.
5. Keep scoring on the server and make it deterministic for a given approved scoring version.
6. Block production activation of a module if its scoring approval status is unresolved.
7. Build golden scoring fixtures and require client/qualified reviewer sign-off before production.
8. Confirm reproduction/online-administration rights for the workbook material before public launch.
